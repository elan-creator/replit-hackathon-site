# Replit Agent 사용법

## 이게 뭐야

**Replit Agent**는 아이디어를 앱, 디자인, 슬라이드 등으로 만들어주는 AI입니다. 일반 언어로 설명하면 끝. 코딩 몰라도 돼요.

Agent는 여러 가지를 만들 수 있어요:
- 웹 앱
- 모바일 앱
- 슬라이드 프레젠테이션
- 애니메이션
- 디자인 목업
- 데이터 시각화
- 자동화 스크립트
- 3D 게임
- 문서/스프레드시트

## 왜 필요해

### 코딩 없이 앱 만들기
전통적인 개발:
1. 코딩 배우기 (몇 달~몇 년)
2. 환경 설정 (몇 시간)
3. 코드 작성 (몇 주~몇 달)
4. 디버깅 (끝없는 고통)
5. 배포 설정 (또 몇 시간)

**Agent 쓰면:**
1. "이거 만들어줘" (5분)
2. 끝

### 실제로 이런 걸 만들 수 있어요
- 팀 프로젝트 트래커
- 카페 랜딩 페이지
- 결제 시스템 추가
- 업무 자동화 툴
- 데이터 대시보드
- 프레젠테이션 슬라이드

## Agent 모드 3가지

Agent는 3가지 작업 모드가 있어요:

### 1. Lite (가벼운 작업)
- **용도:** 빠르고 간단한 수정
- **특징:** 빠르고 저렴
- **예시:** 버튼 색상 바꾸기, 텍스트 수정

### 2. Autonomous (자율 작업) ⭐ 추천
- **용도:** Agent의 모든 능력 활용
- **특징:** 복잡한 기능도 알아서 처리
- **하위 옵션:**
  - **Economy** — 비용 최적화
  - **Power** — 성능 우선 (추천)
- **토글 기능:**
  - **App testing** — 자동 테스트
  - **Code optimizations** — 코드 최적화 (기본 ON)
  - **Turbo** — 더 빠른 처리

### 3. Max (완전 자동)
- **용도:** 장시간 실행되는 큰 프로젝트
- **특징:** 한번 시작하면 끝까지 알아서

> **추천:** 대부분의 경우 **Autonomous + Power**를 쓰세요. 성능과 비용의 균형이 제일 좋아요.

## 따라해봐

### 1단계: 프롬프트 작성하기

좋은 프롬프트 = **What + Look + Work**

**예시:**
```
16개 건반 피아노 만들어줘 (What)
진짜 피아노처럼 흰 건반/검은 건반 배치 (Look)
클릭하면 눌리는 애니메이션 + 실제 음 재생 (Work)
```

**더 좋은 예시들:**
```
팀 프로젝트 트래커 만들어줘
```

```
우리 카페 랜딩 페이지 디자인해줘
```

```
내 앱에 Stripe 결제 추가해줘
```

### 2단계: Agent 시작하기

1. Replit 홈페이지에서 프롬프트 입력창 찾기
2. 원하는 걸 자연스럽게 설명
3. **Start** 버튼 클릭

Agent가 프로젝트를 설정하고 작업을 시작해요.

### 3단계: 진행 상황 지켜보기

**Progress** 탭에서 Agent가 뭘 하는지 실시간으로 볼 수 있어요:
- 파일 만들기
- 코드 작성
- 디자인 적용
- 테스트 실행

### 4단계: 미리보기 확인

**Preview** 탭으로 가면 만들어진 결과를 바로 확인할 수 있어요. 실시간으로 업데이트돼요!

### 5단계: 수정 요청하기

마음에 안 드는 부분이 있어요? Agent한테 다시 말하면 돼요:

```
버튼 색상을 파란색으로 바꿔줘
```

```
로그인 페이지 추가해줘
```

```
모바일에서도 잘 보이게 만들어줘
```

## 협업하기

팀원들과 함께 작업할 수 있어요:

1. **Invite** 버튼으로 팀원 초대
2. 각자 Agent와 대화하며 작업
3. 공유 Kanban 보드에서 진행 상황 확인

- **Core 플랜:** 작업이 순차적으로 처리
- **Pro 플랜:** 여러 작업이 동시에 처리

## 자주 묻는 질문

### Agent에게 메시지 보낼 수 있어?
아니요. Agent는 메신저가 아니에요. 입력하는 모든 것을 작업 지시로 받아들여요. 팀원과의 대화는 Slack이나 Discord를 쓰세요.

### 서로 작업이 덮어씌워지지 않아?
각 작업이 독립된 복사본에서 진행되기 때문에 괜찮아요. 완료되면 메인 버전에 합칠 때 충돌을 해결하면 돼요.

### 팀원이 뭐 하는지 어떻게 알아?
Kanban 보드를 확인하면 active 작업을 볼 수 있어요. 커서 위치와 보고 있는 파일도 실시간으로 보여요.

### 사람을 프로젝트에서 제거할 수 있어?
네. 프로젝트 소유자는 언제든지 팀원을 관리하고 접근 권한을 회수할 수 있어요.
