# Replit이란?

## 이게 뭐야

Replit은 브라우저에서 바로 앱을 만들 수 있는 **AI 기반 개발 플랫폼**입니다. 설치할 것도 없고, 복잡한 설정도 필요 없어요.

## 왜 필요해

### 1. **설치 없이 바로 시작**
- 브라우저만 있으면 끝
- 환경 설정 고민 제로
- 어디서든 접속해서 작업 가능

### 2. **AI가 코딩을 도와줘**
- Agent가 자연어로 앱을 만들어줌
- "이런 거 만들어줘"라고 말하면 끝
- 코드 몰라도 아이디어만 있으면 OK

### 3. **만들고 바로 배포**
- 버튼 하나로 전 세계에 공개
- 링크 하나로 공유
- 서버 걱정은 Replit이 알아서

### 4. **함께 작업하기 쉬움**
- 팀원들과 동시에 편집
- 실시간 협업
- 구글 문서 쓰듯 코딩하기

## Quickstart 가이드

### 새 앱 만들기
1. **AI로 빠르게** — Agent에게 아이디어 설명하고 5분 만에 완성
2. **템플릿 리믹스** — 커뮤니티 앱 가져와서 내 것으로 만들기

### 기존 프로젝트 가져오기
1. **GitHub 연동** — 기존 저장소 2분 만에 임포트
2. **Figma 변환** — 디자인 파일을 React 앱으로 자동 변환
3. **다른 플랫폼에서** — Bolt, Lovable 등에서 프로젝트 가져오기

## 주요 기능

### Workspace 기능
- 📱 **실시간 미리보기** — 코드 바꾸면 바로 결과 확인
- 🚀 **몇 분 만에 배포** — 버튼 하나로 프로덕션 배포
- ⌨️ **완전한 코드 에디터** — VS Code 수준의 편집 환경
- 📱 **모바일 앱** — 스마트폰에서도 코딩 가능
- 🔗 **Git 연동** — GitHub, GitLab 등과 자연스럽게 연결
- 👥 **팀 협업** — 같은 프로젝트를 여러 명이 동시에 편집

### AI 기능
- **Agent** — 앱 전체를 만들어주는 AI 개발자
- **Canvas** — 디자인 여러 버전 비교하고 선택
- **Visual Editor** — 코드 없이 색상, 텍스트 조정

## 엔터프라이즈 지원
