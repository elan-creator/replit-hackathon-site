# 첫 앱 만들기

## 이게 뭐야

5분 만에 진짜 동작하는 피아노 앱을 만들어봐요. 코딩 경험 없어도 괜찮아요. **Replit Agent**가 다 만들어줍니다.

⏱️ **예상 소요 시간:** 5분

## 시작하기 전에

필요한 것:
- Replit 무료 계정 ([replit.com](https://replit.com)에서 가입)
- 웹 브라우저 (Chrome, Firefox, Safari, Edge 아무거나)

> **참고:** Agent는 무료 Starter 플랜에 포함되어 있어요. 매일 크레딧이 충전되고, 신용카드 필요 없어요.

## 따라해봐

### 1단계: 아이디어 설명하기

Agent는 **자연어**로 소통해요. 내가 원하는 걸 말로 설명하면 Agent가 코드를 쓰고, 디자인하고, 동작하는 앱을 만들어줘요.

좋은 프롬프트는 3가지를 포함해요:

1. **뭘 만들지** (What to build)
2. **어떻게 생겼으면 좋겠는지** (How it looks)
3. **어떻게 동작하면 좋겠는지** (How it works)

예시:
```
16개 건반 피아노를 만들어줘. 
진짜 피아노처럼 흰 건반과 검은 건반 배치로 만들어야 해.
각 건반을 클릭하면 실감나게 눌리는 애니메이션과 함께 정확한 음이 나야 해.
```

### 2단계: 시작하기

아래 버튼을 클릭하면 Replit이 열리고 Agent가 작업을 시작해요:

👉 [**피아노 앱 만들기 시작**](https://replit.com/?prompt=Build%20a%20realistic%2016-key%20piano%20with%20proper%20white%20and%20black%20key%20layout%20that%20looks%20exactly%20like%20a%20real%20piano.%20Each%20key%20should%20press%20down%20with%20realistic%20depth%20animation%20when%20clicked%20and%20play%20the%20correct%20note.&referrer=replit-docs)

### 3단계: Agent가 작업하는 걸 지켜보기

Agent가 피아노를 만드는 과정이 **Progress** 탭에 실시간으로 표시돼요.

![Agent가 피아노를 만드는 중](https://mintcdn.com/replit/CKgy3zbnPnUlDukQ/images/getting-started/quickstart_piano_building.png)

약 5분 정도 걸려요. 커피 한 잔 하고 와도 돼요. ☕

### 4단계: 피아노 연주하기

Agent가 완성하면 **Preview** 탭으로 가서 피아노를 직접 연주해보세요!

건반을 클릭하면:
- 눌리는 애니메이션 보여요
- 정확한 음이 들려요

![피아노 연주 데모](https://cdn.replit.com/sanity/quickstart-piano-demo.mp4)

> **참고:** Agent는 같은 프롬프트로도 조금씩 다른 결과를 만들어요. 그래서 내 피아노는 디자인이 약간 다를 수 있어요.

### 5단계: 곡 연주해보기

피아노 건반에 표시된 음 이름을 따라 "Mary Had a Little Lamb"을 연주해보세요:

```
E D C D E E E
D D D
E G G
E D C D E E E D D E D C
```

### 보너스: Canvas로 디자인 변형 만들기

피아노 모양을 바꿔보고 싶어요? **Canvas**를 써서 여러 디자인 버전을 만들고 비교해보세요.

Agent에게 이렇게 말해보세요:
```
캔버스에 피아노 앱의 디자인 3가지 변형을 보여줘
```

![Canvas에 여러 디자인 변형](https://mintcdn.com/replit/4_vaMd7KiBnniEFb/images/getting-started/quickstart_design_canvas_variations.png)

마음에 드는 디자인이 있으면 Agent에게 적용해달라고 하면 돼요.

### 6단계: 앱 배포하기

만든 피아노를 친구들한테 보여주고 싶어요? Workspace에서 **Publish** 버튼을 누르면 공개 URL로 배포돼요. 누구나 접속할 수 있어요!

![앱 배포하기](https://cdn.replit.com/sanity/quickstart-publish-app.mp4)

더 자세한 내용은 [Publishing 가이드](/replit-docs/deploy)를 참고하세요.
